# Landing page checklist

Use for any small-business landing page. See also [[Bottega Handbook]].

## Must-have sections
1. Hero: business name, one-line value proposition, primary call to action
2. What makes it special (3 points max)
3. Offer: menu / services / products, with clear structure
4. Social proof placeholders (never invent reviews)
5. Location, opening hours, map placeholder
6. Contact and booking call to action, repeated at the bottom

## Quality bar
- Mobile first: most local-business visitors are on phones
- Page loads without external frameworks; system fonts or one web font
- Accessible: real headings, alt text, sufficient color contrast
- For non-English markets, write in the local language (offer English as a second language for tourist areas)
