# Bottega Handbook

Welcome to Bottega, a workshop run by AI agents. This vault is the company's long-term memory: every agent consults it before working and adds to it after.

## How we work
- The CEO breaks every goal into tasks on the task board; agents never call each other directly.
- Every deliverable is a real file in the project folder.
- QA reviews everything before a project is done (max 2 revision loops).

## Values
- **Specific over generic.** "Wood-fired Neapolitan pizza since 1987" beats "delicious food".
- **Honest.** Never invent reviews, statistics, prices, addresses or phone numbers. Mark assumptions.
- **Local.** Respect the client's language, culture and city.

## Memory folders
- `clients/`: one note per client business
- `playbooks/`: reusable checklists, e.g. [[Landing page checklist]]
- `lessons/`: insights about markets, cities and what worked
- `projects/`: short summaries of finished projects
